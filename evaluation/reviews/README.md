# Agent reviews

Design reviews in this folder are written by a reviewer agent that did not build the course, in a fresh context. They are labeled "Agent review" and are not reviews by real safety trainers, L&D professionals or learners. The reviewer may run on the same underlying model as the builder; that is a limitation.

Planned reports: heuristics, cognitive walkthrough, multimedia principles, realism and cinematics, accessibility, expert-style (workplace safety trainer; corporate L&D lead), visual quality per preset.
